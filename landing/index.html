Install for VS Code View source

Search Runahead in the Extensions panel, or install it from a terminal.

$ code --install-extension kawas8516.runahead

Downloaded the .vsix from Releases? Install it directly.

$ code --install-extension runahead-0.1.0.vsix

Prefer clicking? Extensions panel → … menu → Install from VSIX…

Build the .vsix yourself. Nothing needs to be published for this to work.

$ git clone https://github.com/kawas8516/runahead && cd runahead && npm install && npm run package --workspace=extension

Needs Node 20.19 or newer. The .vsix lands in extension/.

Tab to accept

Then three steps, once.

The extension does nothing until you give it a key. That is the whole configuration.

  1. Get an OpenRouter key

    Sign up at openrouter.ai/keys. A free account is enough to start.

  2. Paste it into VS Code

    Run Runahead: Set OpenRouter API Key from the command palette. It's checked against OpenRouter before it's saved.

  3. Start typing

    Completions appear as you write. Press Tab to accept. Change the model any time from the status bar.

What it actually does.

Inline completions

Ghost text as you type, using the code around your cursor, your imports, and the files you edited recently.

NextEdit predictions

Predicts the follow-up edits a change implies, not just the next token. Needs a model fine-tuned for it, so it stays off unless you pick one.

Any OpenRouter model

Hundreds of models behind one key, free tiers included. Small fast models usually feel better here than large slow ones.

Control from the status bar

Toggle completions, switch models, replace your key, or clear the cache without opening a settings file.

It's free because you're paying OpenRouter, not us.

There is no server in the middle. The extension talks to OpenRouter with your key and nothing else, which is why there's nothing to charge for.

Your key stays yours

Stored in your operating system's credential store. Never written to settings.json, never logged, never sent anywhere except OpenRouter.

No telemetry, no account

No analytics, no sign-up, no phone-home. There is no backend to collect anything even if we wanted to.

Small enough to audit

3.9 MB packaged, Apache-2.0, and the interesting parts are a few thousand lines. Read it before you trust it.

Built carefully, and honestly.

Plenty of thin wrappers exist. Here is what was actually done, including the parts that aren't finished.

3.9 MB
The packaged extension. Cut from 9.96 MB to 6.71 MB by lazy-loading the AWS and Google SDKs that ship inside the upstream engine but can never be reached here.
879 tests
Passing, in the core engine. Four unrelated diff tests fail on a clean checkout of upstream and still do; claiming a green board would be a lie.
One real bug
The completion cache's native SQLite binding silently breaks when bundled, because the bundler collapses the call-site detection it relies on. Found by reading the extension host log, not by a test.
Zero added deps
The edit-preview renderer was rewritten by hand rather than restoring the original's three-package syntax-highlighting stack. Fewer megabytes, less to trust.
Not done yet
NextEdit through OpenRouter is unverified end-to-end, and the packaged build has only been tested on Windows. Both are written down rather than glossed over.
The name
Runahead execution is a real processor technique: when the CPU stalls, it runs ahead of where it is to prefetch what it will probably need, and throws the work away when it guesses wrong. That is this extension, at the scale of a keystroke.

Bring your own key.

Install it, paste a key, keep typing. If it isn't for you, uninstalling leaves nothing behind.
